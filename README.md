## 🚀 Getting Started

### Prerequisites
* Node.js and npm installed. *(Update if applicable)*
```bash
npm install npm@latest -g
```

### Installation & Running the Server
1. Clone the repo:
   ```bash
   git clone https://github.com/Zaphod625/EPE321.git
   ```
2. Navigate to the server directory:
   ```bash
   cd Progress_Demo/New_Server
   ```
3. Install NPM packages:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```
